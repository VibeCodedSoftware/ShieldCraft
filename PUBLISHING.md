# Publishing ShieldCraft

This is an engineering checklist, not legal advice. If ShieldCraft is ever distributed commercially
or at scale, have a qualified person review it.

## Checked and cleared

| Item | Status |
|---|---|
| ShieldCraft's own code | Open source: **MIT OR Apache-2.0** (`LICENSE-MIT`, `LICENSE-APACHE`, `NOTICE`). |
| Third-party code compiled in | 326+ Rust crates, all permissive (MIT, Apache-2.0, BSD, Zlib, ISC, Unicode-3.0, CC0, BSL-1.0, MPL-2.0 unmodified). Per-crate license files are in `licenses/crates/`, regenerated by `scripts\generate-notices.ps1`. No GPL code is included. |
| Hope:RE port (`crates/shieldcraft-core/src/engines/hope/`) | MIT, © 2025 HopeArtOrg. Its license text ships in `licenses/Hope-RE-MIT.txt`, and attribution is in the source header and `NOTICE`. |
| Hope:RE ONNX models (~1 GB) | **Not** in the repository or the package. The app downloads them, after the user confirms, from Hope:RE's own GitHub releases, with pinned SHA-256 hashes. |
| ONNX Runtime DLL (`third_party/onnxruntime/`) | Official Microsoft build, MIT. Its license and ThirdPartyNotices ship alongside it. |
| Fonts | egui's bundled fonts (UFL 1.0, Hack/Bitstream Vera, OFL 1.1, MIT). Their texts are in `licenses/FONTS.txt`. |
| Mist v1, Nightshade release, InkShield | Not included in any form (no code, no adapter, no menu entry, no credit listing needed). |
| PhotoCraft, ArtCraft | Design references only. No code, branding, fonts or assets copied. |
| Lantern | External hosted service, **not open source**. ShieldCraft calls its documented public API only on user action. No Lantern code, models or data are included. Its docs state third-party apps may use the API, and its Terms govern use. |
| Secrets and personal data | Source, docs and scripts scanned: no API keys, tokens, passwords, personal paths, user names or machine details. Release binaries are built by `scripts\package.ps1` with `--remap-path-prefix`, and the script refuses to package an exe that still contains the builder's user-profile path. |
| Build output | `target/` and `dist/` are excluded by `.gitignore`. Publish release packages as release assets, not in the source tree. |

## Things only you can confirm

1. **The app icon (`assets/icon-source.png`).** Publishing it requires that you have the right to
   share it. If you made it with an AI image tool, check that tool's terms for public and
   commercial use. If someone else made it, you need their permission.
2. **The name "ShieldCraft".** I can't run a trademark search. Do a quick search (for example
   the USPTO's trademark search) for existing uses in software. Note that ArtCraft brands its own
   apps with a "-Craft" suffix.
3. **Grid Noise Animator's techniques.** That project has no license. ShieldCraft contains none of
   its code, text or assets and credits its creator. The implementation was written after studying
   its source, though, so it is not a clean-room implementation. Ideas and algorithms aren't
   protected by copyright, but the courteous and lowest-risk step is to ask the author
   (stelmosfire13-alt) to confirm they're happy with it, or to add a license, for example through a
   GitHub issue.
4. **Third-party names.** Glaze and Nightshade (University of Chicago), Hope:RE, Lantern and
   others are named only to describe compatibility and credit. `NOTICE` and the Licenses window
   state that ShieldCraft is not affiliated with any of them. Don't use their logos.

## Releasing

1. `powershell -ExecutionPolicy Bypass -File scripts\package.ps1` builds (with local paths stripped), regenerates notices, and
   creates `dist\ShieldCraft-<version>-win64.zip` with a `.sha256`.
2. Push the source (without `target/` and `dist/`) to a public repository, and set the
   repository URL in the "ShieldCraft" entry of `crates/shieldcraft-core/src/licenses.rs`.
3. Attach the zip and its `.sha256` to a release.

`scripts\package-public.ps1` bundles both parts into `dist\ShieldCraft-<version>-public.zip`
(source tree in `ShieldCraft\`, release files in `release-assets\`, plus `UPLOAD.txt`).
